**LagBar** — лёгкая перемещаемая информационная панель для World of Warcraft, которая отображает текущий FPS, задержку соединения, сетевой трафик и общее потребление памяти аддонами.

Разработан для **World of Warcraft 3.3.5a**.

</div>

## Возможности

LagBar предоставляет компактную сводку о текущей производительности игрового клиента и состоянии сетевого соединения.

Аддон может отображать:

- **FPS** — текущее количество отрисованных кадров в секунду.
- **Задержку** — текущую задержку соединения в миллисекундах.
- **Входящий трафик** — текущую скорость загрузки в КБ/с.
- **Исходящий трафик** — текущую скорость отправки в КБ/с.
- **Память аддонов** — общий объём памяти, используемый загруженными сторонними аддонами.
- **Динамические цвета** — значения меняют цвет от зелёного к жёлтому и красному в зависимости от их качества.
- **Автоматическую ширину** — окно расширяется при включении дополнительных показателей.
- **Сохранение настроек** — положение, масштаб, блокировка, фон и параметры отображения восстанавливаются между сессиями.

FPS и задержка отображаются постоянно. Сетевой трафик и память аддонов включаются отдельно.

## Подсказка использования ресурсов

Когда отображение памяти включено, наведите курсор на LagBar, чтобы открыть подробную подсказку.

В подсказке отображаются:

- **15 аддонов с наибольшим потреблением памяти**;
- объём памяти в КБ или МБ;
- использование процессорного времени аддонами, если включено профилирование Lua.

Информация о процессорном времени доступна только при включённой переменной клиента `scriptProfile`.

> Профилирование Lua может снизить производительность игры. Включайте его только для диагностики аддонов.

## Перемещаемое окно

LagBar можно разместить в любой части экрана.

- Перемещайте разблокированное окно **левой кнопкой мыши**.
- Нажмите по окну **правой кнопкой мыши**, чтобы заблокировать или разблокировать его.
- Используйте `/lagbar reset`, чтобы вернуть окно в центр экрана.
- Используйте `/lagbar scale`, чтобы изменить его размер.

Выбранное положение, масштаб и состояние блокировки сохраняются автоматически.

## Команды

Введите `/lagbar` без аргументов, чтобы вывести список доступных команд в чат.

| Команда | Описание |
| --- | --- |
| `/lagbar reset` | Сбросить положение окна и переместить его в центр экрана. |
| `/lagbar bg` | Показать или скрыть фон окна. |
| `/lagbar scale <значение>` | Изменить масштаб окна. |
| `/lagbar memory` | Включить или отключить отображение общей памяти аддонов. |
| `/lagbar net` | Включить или отключить входящий и исходящий сетевой трафик. |

Примеры изменения масштаба:

```text
/lagbar scale 0.75
/lagbar scale 1
/lagbar scale 1.25
/lagbar scale 1.5
```

## Установка

1. Скачайте последнюю версию со страницы [Releases](https://github.com/darhanger/LagBar/releases).
2. Распакуйте загруженный архив.
3. Скопируйте папку аддона `LagBar` в:

```text
World of Warcraft\Interface\AddOns\
```

4. Убедитесь, что структура папок выглядит примерно так:

```text
World of Warcraft
└── Interface
    └── AddOns
        └── LagBar
            ├── LagBar.toc
            ├── LagBar.xml
            ├── LagBar.lua
            ├── Locales
            ├── AceLocale-3.0
            └── LibStub
```

5. Перезапустите игровой клиент.
6. Включите **LagBar** в списке модификаций на экране выбора персонажа.

## Использование

LagBar запускается автоматически после входа в игру.

Обычная последовательность настройки:

1. Нажмите по LagBar правой кнопкой мыши, чтобы разблокировать окно.
2. Перетащите его в нужное место.
3. Повторно нажмите правой кнопкой мыши, чтобы заблокировать окно.
4. Включите дополнительные показатели командами `/lagbar memory` и `/lagbar net`.
5. Настройте размер командой `/lagbar scale <значение>`.

Для работы не требуются внешние библиотеки или отдельный аддон настроек.

## Производительность

LagBar обновляет отображаемую статистику один раз в секунду.

Аддон не формирует текст повторно, если значения не изменились. Список загруженных аддонов кэшируется, а подробный рейтинг использования памяти рассчитывается только при открытии подсказки.

Для мониторинга памяти World of Warcraft должен обновлять статистику аддонов, поэтому постоянно включённый параметр `/lagbar memory` создаёт немного больше нагрузки, чем отображение только FPS и задержки.

## Поддержка ElvUI

LagBar автоматически определяет наличие ElvUI и изменяет оформление рамки, чтобы она лучше сочеталась с интерфейсом на основе ElvUI.

ElvUI является необязательным и не требуется для работы аддона.

## Совместимость

- World of Warcraft **3.3.5a**
- Версия интерфейса **30300**
- Lua **5.1**
- Стандартный интерфейс Blizzard
- Необязательная интеграция с ElvUI
- Система локализации AceLocale-3.0

На сильно изменённых пользовательских клиентах поведение может отличаться, если реализации `GetNetStats`, профилирования аддонов или сохранённых переменных не соответствуют оригинальному клиенту.

## Для чего нужен LagBar?

LagBar предоставляет основную информацию о производительности без необходимости открывать системное меню игры или устанавливать большой комплекс мониторинга.

Аддон может пригодиться для:

- контроля FPS в рейдах и на полях боя;
- обнаружения скачков задержки;
- наблюдения за входящим и исходящим трафиком;
- проверки общего потребления памяти аддонами;
- поиска аддонов с чрезмерным использованием памяти;
- профилирования процессорного времени при разработке аддонов;
- проверки производительности после изменения интерфейса.
